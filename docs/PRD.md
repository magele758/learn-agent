# PRD：Learn Agent

状态：草案，2026-11-10。工作目录是本仓库根目录。开源仓库还没建。

## 问题

问一个聊天模型，它会直接给答案。它不先看你哪里没懂，不按前置依赖往下教，也不把你真正站得住的命题留下来。下次还是从零开始。

## 要做的产品

一个帮助一个人学难东西的 Agent。对一个主题，它做四件事：

1. 测量：用少量问题看出哪些命题已经站得住，哪些还没有。
2. 计划：把还没懂的内容排成依赖顺序，不跳步。
3. 教学：一次只教一个推理步骤，要求把「为什么」说出来。
4. 练习：立刻用回忆而不是照读来检查这一步。

学过的东西写成本地知识图谱：命题、依赖、推理链、最近一次练习。不用一个分数代表「学会了」。

## 使用者

一个人，自学一个明确主题。第一版只有命令行。没有账号，没有多人。

## 运行时

模型回合、工具调用和停止条件用本机 `ppeng-agent-core/packages/agent-loop`。学习阶段（测、计划、教、练）和命题图不放进那个包，放在本目录。

模型走 agent-loop 已有的 OpenAI 兼容适配器。密钥只来自环境变量，不写进仓库。

## 做法来源

- LearnHarness：测量、计划、单步教学、练习；命题图而不是分数；本地数据；模型可替换。不复制它的 AGPL-3.0 源码。
- dsh-deeptutor：学习路径、自测、笔记以后可以检索。第一版不做 RAG。
- ITS skill 的描述：一次只引入一个概念；间隔复习放到第二版，第一版不实现 BKT。
- agent-loop：只借用循环，不把学习产品写进 ppeng-agent-core。

## 界面

第一版仍然只有命令行。图形界面用 SwiftUI，只做 macOS。

SwiftUI 是这台机器上最接近系统原生的绘制和交互。Rust 可以做跨平台原生界面，但 LearnHarness 用的 Tauri 是 Rust 壳加网页，渲染仍在 WebView，不是这条路上的极致原生。若以后要同一套界面覆盖 Windows 和 Linux，再把壳换成 Rust，学习核心不跟着重写。

学习循环和命题图留在本目录的 TypeScript，并调用 `@ppeng/agent-loop`。Swift 只做界面，通过本机进程读写 `data/graph.json` 和会话命令，不把 agent-loop 重写成 Swift 或 Rust。

## 第一版范围

命令行可以：

- 新建一个主题会话。
- 对当前命题做一次测量，并写入图谱。
- 给出下一步要教的命题，以及它依赖哪些尚未稳定的命题。
- 教这一个步骤，并留下推理链。
- 出一道要靠回忆回答的练习，把结果写回命题状态。
- 把图谱存成这个项目目录里的 JSON。

第一版不做：桌面应用、网页、语音、账号、订阅、云同步、间隔调度、把 LearnHarness 的界面或源码搬过来。

## 成功标准

在本目录执行一次本地会话后，磁盘上的图谱同时有：至少一个命题、一条依赖或「无前置」的记录、一条教学推理、一条练习结果。全程不需要把源码抄自 LearnHarness。
