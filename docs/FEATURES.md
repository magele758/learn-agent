# 功能列表

标识在第一版里要能指认。P0 是第一版，P1 是图能跑之后，P2 先不做。

## P0

| ID | 功能 | 完成时能看到 |
| --- | --- | --- |
| F1 | 命题 | 一条命题有 id、正文、状态。状态只使用 `unknown`、`learning`、`stable`。 |
| F2 | 依赖 | 一条边表示「学会 A 之前需要 B」。没有前置时显式记为空，不靠缺字段猜测。 |
| F3 | 推理链 | 一次教学留下「因为什么，所以这个命题」。 |
| F4 | 本地存储 | 图谱是本目录下的一个 JSON 文件。重启后还在。没有网络存储。 |
| F5 | 测量 | 一次测量会改写相关命题的状态，并记下依据，不产生总分。 |
| F6 | 计划 | 给出下一个要教的命题。若它的前置还不是 `stable`，先指出那个前置。 |
| F7 | 单步教学 | 一次只讲一个命题，并写入一条推理链。 |
| F8 | 练习 | 一道不能靠照读刚才讲解来回答的题。结果只更新这一题涉及的命题。 |
| F9 | 会话阶段 | 阶段只有 `measure`、`plan`、`teach`、`practice`。命令行能看出当前阶段。 |
| F10 | 模型循环 | 需要模型时调用 `@ppeng/agent-loop` 的 `createAssembledLoop`。不在本目录再写一套模型循环。 |
| F11 | 命令行 | 能新建主题、看图谱、推进一步。没有图形界面。 |

## P1

| ID | 功能 | 说明 |
| --- | --- | --- |
| F12 | 间隔复习 | 按上次练习时间挑选命题，不在第一版做。 |
| F13 | 笔记检索 | 只检索本人笔记，不把网页搜索当学习记录。 |
| F14 | 图示 | 把一个推理步骤写成 mermaid 或 svg 文件，不做白板。 |
| F15 | macOS 界面 | SwiftUI。只包一层命令和图谱，不重写 agent-loop。命令行跑通之后再做。 |

## P2

桌面壳、语音、账号、云同步、订阅。第一版不设计这些的接口。

## 明确不做

- 不复制 https://github.com/amosblomqvist/learnharness 的源码。
- 不把命题状态折成一个掌握分数。
- 不在没有题集的情况下声称实现了 BKT。
- 不修改 `ppeng-agent-core` 的服务、SOP 或正在运行的进程。
